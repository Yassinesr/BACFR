First, let's talk about my model. In the checkpoints/BACFR directory, you can find the complete best result of one training session. There are a total of 20 epochs, so 20 weight files have been saved. You can view the log contents during the training process from the log files. BACFR.yaml and BACFR.py are the model files. Train_patch.py is the training code.
In addition, in the results_cl directory, you can find the optimized results for the test set under different benchmarks. This includes the results of the complete model and ablation experiments. 
For your training process, first, you need to create a yaml file in the configs directory to save your training configuration, hyperparameters, etc. Then, build your model code files in the lib directory. Finally, call the Train_patch.py file in the run directory to start the training. For the overall training process, you need to study and understand the general training procedure and the functions of each parameter. During testing, simply call the Test_patch.py file in the run directory. Similarly, you also need to master the parameters inside. In the lib directory, other contents from the original UACANET project are also saved. The backbone and loss are all called from the UACANET code. You can view them through code navigation.
